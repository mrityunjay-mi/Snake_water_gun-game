# Snake, Water, Gun Game 🐍💧🔫

This is a fun, text-based Python game I built while learning the basics of programming. 

* *Credits:* Built by following the Python tutorial series by    *CodeWithHarry*.

* *What I Practiced:* Using conditional logic (if-elif-else), managing user input, and importing the random module while also getting a deeper understanding of lists and dictionaries.

## 🤖 How to play
Snake , water , Gun is a classical Indian variant of Rock , Paper , Scissors:
* **Snake** drinks **Water** (Snake wins)
* **Water** douses **Gun** (Water wins)
* **Gun** shoots **Snake** (Snake  wins)

### ⛷️How to Run
1. clone this repository to your local machine
2. open your terminal
3. execute it using:
   ''' bash
   python main.py
   '''
